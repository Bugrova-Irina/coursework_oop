# Программа, которая получает информацию о вакансиях с платформы hh.ru в России

## Описание:

Созданы классы для подключения по API к hh.ru и получения данных о вакансиях HeadHunter,
класс для работы с вакансиями Vacancy, класс для работы с файлами FileRepository (сохранение,
чтение, добавление, удаление данных). Для подключения к сайту и работы с файлами созданы 
абстрактные классы.

Есть функция для взаимодействия с пользователем, которая запрашивает у пользователя ключевое 
слово и количество вакансий для вывода в топ-N. Функция объединяет все классы и выводит в 
консоль отфильтрованные по заданным пользователям параметрам в консоль.

## Требования к окружению:

Установите:
 - python 3.13.0
 - Poetry
 - requests
 - Pytest
 - pytest-cov

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/Bugrova-Irina/job_posting_parser/
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
```
poetry add requests
```
```
poetry add --group dev pytest
```
```
poetry add --group dev pytest-cov
```
