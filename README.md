# Ядро для интернет-магазина

## Описание:

Созданы классы 

## Требования к окружению:

Установите:
 - python 3.13.0
 - Poetry
 - requests
 - Pytest
 - pytest-cov

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/Bugrova-Irina/coursework_oop/
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
```
poetry add requests
```
```
poetry add --group dev pytest
```
```
poetry add --group dev pytest-cov
```
## Использование:

Использование классов 

## Тестирование:
В папке tests для модулей созданы тесты. Проверяется корректность инициализации объектов классов 

Тестирование выполняется командой pytest в терминале.
